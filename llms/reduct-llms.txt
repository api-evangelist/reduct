# Reduct

> Reduct is a video intelligence platform that transcribes, translates, redacts, searches, annotates, and edits audio and video using a text-based editor. Reduct exposes a RESTful API (v3) giving broad programmatic access across a workspace — projects, recordings, media, transcripts, redactions, highlights, comments, and reels — on Professional and Enterprise plans.

## API

- [API access guide](https://help.reduct.video/en/articles/api-access): Overview of the RESTful API (v3), supported objects, and how to generate API keys via the backstage interface (Professional/Enterprise plans).
- Authentication: per-workspace API key, presented in a request header. See authentication/reduct-authentication.yml.
